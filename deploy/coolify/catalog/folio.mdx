# What is Folio?

Folio is an open-source wiki that replaces Confluence and Notion for a team.
Pages are plain Markdown files in a Git repository you control. People edit them
in the browser together, in real time; AI agents read and write the same pages
over MCP.

## Notes

The first account you create becomes the administrator. Set the domain on the
`folio` service before the first deploy; the app builds invitation and share
links from it.
